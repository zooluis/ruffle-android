這是針對 [Ruffle](https://ruffle.rs) 的原生 Android 應用程式。

它處於非常早期的階段。

# 預建置 APK

[<img src="https://fdroid.gitlab.io/artwork/badge/get-it-on.png" alt="Get it on F-Droid" height="75">](https://f-droid.org/packages/rs.ruffle/)

最新版本[（此處）](https://github.com/ruffle-rs/ruffle-android/releases)應上傳了若干 `.apk` 檔案作為資產。

你可以下載並安裝其中一個來試用此應用程式。

- **對於絕大多數現代手機、平板、單板電腦和小型遊戲主機，你需要 `arm64-v8a` 版本。**

- `armeabi-v7a` 版本用於較老的、32 位元 ARM 裝置。

- `x86_64` 版本用於一些罕見的 Intel/Microsoft 平板和/或 Chromebook，以及/或在 Android-x86 或 Waydroid 等環境中的 PC 上執行。

- `x86` 版本主要只是為了完整性。

- `universal` 版本應可在以上全部 4 種架構上執行，但它_巨大_。
