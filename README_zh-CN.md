这是针对 [Ruffle](https://ruffle.rs) 的原生 Android 应用。

它处于非常早期的阶段。

# 预构建 APK

[<img src="https://fdroid.gitlab.io/artwork/badge/get-it-on.png" alt="Get it on F-Droid" height="75">](https://f-droid.org/packages/rs.ruffle/)

最新版本[（此处）](https://github.com/ruffle-rs/ruffle-android/releases)应上传了若干 `.apk` 文件作为资源。

你可以下载并安装其中一个来试用此应用。

- **对于绝大多数现代手机、平板、单板计算机和小型游戏主机，你需要 `arm64-v8a` 版本。**

- `armeabi-v7a` 版本用于较老的、32 位 ARM 设备。

- `x86_64` 版本用于一些罕见的 Intel/Microsoft 平板和/或 Chromebook，以及/或在 Android-x86 或 Waydroid 等环境中的 PC 上运行。

- `x86` 版本主要只是为了完整性。

- `universal` 版本应可在以上全部 4 种架构上运行，但它_巨大_。
